# Lista de Filmes

Atividade em React para controle e gerenciamento de filmes assistidos.

## Funcionalidades

- Listagem de filmes (título, gênero e ano).
- Botão para alternar status entre assistido e pendente.
- Contadores dinâmicos de filmes assistidos, pendentes e total.

## Como Executar

```bash
# Instalar dependências
npm install

# Rodar a aplicação
npm run dev
